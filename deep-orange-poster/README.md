# Deep Orange — House Event Poster

A standalone, responsive React and Vite project based on the selected event-poster design.

## Run locally

```bash
npm install
npm run dev
```

## Build for production

```bash
npm run build
npm run preview
```

## Customize the poster

- Edit the event name and details in `src/App.jsx`.
- Adjust the poster color, typography, and layout in `src/style.css`.
- Replace `src/assets/house-figure-cutout.png` to feature a different image.

The poster uses the Playfair Display font from Google Fonts. It falls back to Georgia if the font cannot be loaded.
