# Onestop

A standalone React storefront demo with a sky-blue and white identity. Browse sample products across electronics, fashion, home, beauty, and everyday categories; search the catalog; and add items to a cart saved in local storage.

## Run locally

```bash
npm install
npm run dev
```

## Build and preview

```bash
npm run typecheck
npm run build
npm run preview
```

## Demo limitations

The catalog is sample data. Cart contents are stored in this browser only. There is no live inventory, checkout, payment processing, or order creation.
